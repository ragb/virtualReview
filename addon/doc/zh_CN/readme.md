## 概述
此插件允许 NVDA 用户在文本框中对窗口内容进行浏览，类似于 JAWS for Windows 的窗口虚拟化功能。
请注意，此功能仅为用户提供便利，并不能替代 NVDA 卓越的浏览模式和对象导航支持。

## 用法
Press NVDA+alt+w to open the virtual revision Window.
随后即可像处理其他文本内容一样对显示的文本框进行导航。
按 Escape 键可关闭虚拟浏览窗口。
